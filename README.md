## লাইভ সাইট দেখতে

1. GitHub রিপোজিটরিতে যান: https://github.com/a02855048-hub/casino-site
2. **Settings** → **Pages** এ যান
3. Source হিসেবে **Deploy from a branch** সিলেক্ট করুন
4. Branch: `main` / folder: `/ (root)` সিলেক্ট করে **Save** করুন
5. কয়েক মিনিট পর সাইট লাইভ হবে এই লিংকে:
   **https://a02855048-hub.github.io/casino-site/**
